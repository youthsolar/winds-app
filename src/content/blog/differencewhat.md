冥界謝必安大將軍（七爺）聖詞曰：「勿以斬心渡靈、勿以渡心斬魔。」

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **靈界影響比較** | | | | |
| 狀態 | 對應單位 | 標的 | 因果規則 | 法師基本作為 |
| 冤親債主 | 地府 / 執行 | 元辰內大五行（財、情居多） | 符合 | 談判、化解恩債 |
| 入陰 | 地府 / 審判 | 元辰外大五行（健康居多） | 大多數不符合 | 閻殿緝拿歸案 |
| 入魔 | 天庭 / 武部 | 元辰內小五行（頂輪：元神閣樓） | 不符合 | 請令後斬滅 |

冤親債主是與我們有未了的因緣或仇怨的眾生，祂們可能會影響我們的身心運勢，也有可能是我們累世的善緣或親人。冤親債主不應該用對抗的方式來處理，而是用化解的方式來處理。我們應該用平等、慈悲與智慧的心去對待祂們，幫助其解脫苦難以消除冤業、得到安樂。

冤親債主的問題，也常常是我們累世言行與自身（累世記憶）目前的問題，因為我們與祂們有著深厚的因果關係。所以我們平時應該多做善事，累積功德以增強自己的能量場，減低冤親債主對我們的影響，並且修正自己的心態，不要再造惡業。

![12668435](https://cdn.winds.tw/es/db8382995e_12668724.jpg)

入陰是指被冥界眾生附身（寄生）在肉體上，造成身心不適或運勢不順的現象，當能量太弱、陽炁不足、行運不佳、年老體衰等等，都會使人的炁場變弱，容易讓冥界眾生乘虛而入，導致身心靈不濟、作息日夜顛倒引發莫名病痛。
